# 搜索框布局

## 原理

主窗口 `MainWindow.xaml` 的压缩包标题行使用两列 `Grid`：左列显示当前格式文字，右列显示 `searchBox`。列宽按 `1*` 与 `2*` 分配。文件列表直接占下一行，不再为搜索框另设一整行。布局由窗口可用空间决定，没有为搜索框声明固定宽度或高度。

## 调用方式

打开压缩包后，在标题文字右侧输入搜索词。`SearchBox_TextChanged` 调用 `SearchEntriesAsync`，清空搜索框则恢复当前目录列表。控件的提示文字由 `SearchEntries` 本地化资源提供。

## 验证

缩放主窗口，确认标题与搜索框仍在同一行；搜索、清空搜索以及目录导航沿用原来的异步搜索路径。
