# 异步、进度、本地化与布局约定

新增界面的文本来自 `UiStrings.resx` 及 `en-US`、`zh-CN`、`zh-TW`、`zh-HK`、`zh-MO` 五份区域资源；默认英文资源与英文区域资源保持一致。新增的菜单、状态、错误说明和首次使用按钮不在代码中硬编码用户可见文本。

主窗口的压缩、解压、搜索和拖出暂存沿用异步任务；主窗口状态栏和进度条显示进展，停止按钮取消当前归档任务。首次使用窗口在后台创建配置并显示进度；系统集成窗口逐项报告右键菜单和扩展名关联结果。原生 Windows 文件/目录选择器保持系统模态交互，耗时文件操作在其返回后异步执行。

两个新增窗口使用 `WpfUi.SizeWindow` 按当前工作区比例定初始尺寸。控件仅由 `Grid` 的 `Auto` 和星号行列、边距及内容决定尺寸，不指定固定宽度或高度。用户可缩放窗口，长文本和进度日志可滚动。
