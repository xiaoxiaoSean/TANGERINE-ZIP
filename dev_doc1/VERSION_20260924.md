# 应用版本号单一来源（2026-09-24）

## 修改版本

主程序版本号只在 `TANGERINE-ZIP/TANGERINE-ZIP.csproj` 的 `<Version>` 元素中填写一次，例如 `<Version>1.1.0.0</Version>`。`AssemblyVersion`、`FileVersion` 和 `InformationalVersion` 都引用这一属性。修改后必须重新编译或发布；已经生成的 EXE 不会自动变化。

“关于”窗口通过 `typeof(AboutWindow).Assembly.GetName().Version` 读取编译进程序集的版本号，显示为四段式版本，和 Windows 资源管理器“属性 → 详细信息”的文件版本、产品版本一致。按照界面要求，详细信息正文保留原有英文和原有措辞，不进行本地化；只把正文中两处当前版本号改为动态读取。更新记录中的 `1.0.0` 表示历史起始版本，不是当前程序版本。读取版本失败时抛出 `ABTWN0001`；主窗口以 `MAINW0019` 作为其他关于窗口错误的阶段码显示错误。

## 获取当前版本

- 在程序中打开“关于”，首行显示当前正在运行的程序版本。
- 在 Windows 资源管理器中右键 `TANGERINE-ZIP.exe`，选择“属性 → 详细信息”，查看“文件版本”或“产品版本”。
- 在 PowerShell 中运行：`(Get-Item 'TANGERINE-ZIP.exe').VersionInfo.FileVersion`。路径应换成实际 EXE 路径。
- 在 C# 代码中读取：`typeof(AboutWindow).Assembly.GetName().Version?.ToString(4)`。

`TANGERINE-ZIP.ContextMenuPackage/AppxManifest.xml` 的 MSIX 包版本 `2.3.0.0` 是独立的右键菜单扩展安装/升级标识，不是主程序版本；其兼容性检查也使用这个独立版本。不要把它当作“关于”窗口的应用版本。

本次已以 Release 配置编译，检查生成 EXE 的文件版本与产品版本均为 `1.1.0.0`。关于窗口正文未使用本地化资源；版本读取失败提示仍有六种语言资源。
