# 命令行调用

同一个 `TANGERINE-ZIP.exe` 保留图形界面：无参数时打开主窗口，传入单个现有压缩包路径时在主窗口打开该文件。传入以下命令时在终端运行，不创建图形窗口；成功返回退出码 `0`，执行失败返回 `1`，取消或默认的冲突终止返回 `2`。命令名不区分大小写；参数名称请按示例写小写。

首次使用命令前，先在图形界面的“设置 → 更多”设置临时目录。命令执行时直接读取 exe 同目录的 `TEMP_D`，该目录不可达或空间不足时会在标准错误输出中报告 StageCode，不弹出设置窗口。`help` 不依赖临时目录。命令使用与图形界面相同的工作进程、资源预检和解压路径安全检查。

## help

```powershell
TANGERINE-ZIP.exe help
TANGERINE-ZIP.exe help compress
TANGERINE-ZIP.exe help extract
TANGERINE-ZIP.exe help list
```

## compress

```powershell
TANGERINE-ZIP.exe compress <输出文件> <来源文件或目录>... [参数]
TANGERINE-ZIP.exe compress backup.7z C:\Data --level 7 --threads 4
```

| 参数 | 含义 |
|---|---|
| `--format zip\|7z\|rar\|tar\|gz\|bz2\|xz\|lz4\|zst\|iso\|wim` | 指定格式；省略时按输出文件后缀判断。 |
| `--password 密码` | 压缩密码，仅 ZIP、7z、RAR 支持。密码可能出现在进程参数列表中。 |
| `--password-env 变量名` | 从指定环境变量读取密码，与 `--password` 二选一。 |
| `--level 0..9` | 压缩等级；RAR 上限为 5，默认 5。 |
| `--method Default\|Deflate\|LZMA2` | 压缩算法，默认 `Default`。ZIP 不支持 LZMA2，7z 不支持 Deflate。 |
| `--dictionary MiB` | 字典大小，范围 1–1024，默认 16。 |
| `--threads 数量` | 线程数，范围 0–128，0 表示自动。 |
| `--memory-limit MiB` | 内存上限，0 表示不限制。 |
| `--volume MiB` | 分卷大小，0 表示不分卷。 |

高级参数仅用于 ZIP、7z、RAR。输出文件或第一卷已存在时拒绝创建，避免覆盖。高等级、大字典和高线程数会增加内存及 CPU 占用；大字典也可能使低配置设备解压缓慢，非默认算法可能降低兼容性。

## extract

```powershell
TANGERINE-ZIP.exe extract <压缩包> <目标目录> [参数]
TANGERINE-ZIP.exe extract backup.zip C:\Restored --entry docs/readme.txt --on-conflict skip
```

| 参数 | 含义 |
|---|---|
| `--password 密码` / `--password-env 变量名` | 解密密码；两者互斥。 |
| `--encoding 名称` | 成员文件名编码，例如 `gb18030`。 |
| `--entry 成员路径` | 只解压指定成员，可重复；目录选择会包含其下文件。 |
| `--on-conflict abort\|overwrite\|skip` | 目标文件已存在时的处理，默认 `abort`。 |
| `--on-issue abort\|skip` | 路径穿透、可疑膨胀或单文件错误时的处理，默认 `abort`。`skip` 会跳过问题成员。 |

命令行默认保守处理冲突和安全警告，不等待图形确认。解压前估算目标磁盘和内存余量，过程中仍由归档服务复核。建议先用 `list` 确认成员路径。

## list

```powershell
TANGERINE-ZIP.exe list <压缩包> [--encoding 名称] [--password 密码]
TANGERINE-ZIP.exe list backup.zip --json
```

默认输出制表符分隔的成员路径、原始字节数、压缩后字节数与压缩方式；缺失值显示 `-`。路径中的制表符、换行与反斜杠会转义。`--json` 输出完整成员元数据，包括修改时间、CRC 和加密状态；还支持 `--password-env 变量名`。

命令参数中的路径包含空格时请用终端引号包住；以 `--` 开头的来源路径前可写一个单独的 `--` 终止参数解析。
