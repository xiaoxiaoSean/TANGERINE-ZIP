# 变更记录：2026-09-27

## 新增

- 菜单栏“压缩包工具”及完整性测试、损坏探测与可读文件恢复、Hash 显示和校验、文件名编码切换四个入口。
- 压缩配置窗口与 `ADVANCED_MENU_ON` 空文件开关；主窗口和资源管理器右键压缩使用同一配置模型。
- ZIP/7z/RAR 高级写入参数、分卷输出和 Windows Job Object 内存上限。
- 压缩包内文件名并行搜索、三列列表、单成员右键解压与详细信息。
- 文件详细信息新增成员类型、归档格式、压缩方式、压缩率、节省空间、修改时间、加密状态和 CRC32；无法可靠获取的数据标为未知。
- 同一 exe 增加 `help`、`compress`、`extract`、`list` 命令及参数；无参数仍进入图形界面，命令行支持标准输出、标准错误和退出码。
- 文件拖入时按当前任务状态询问同实例切换或启动新实例。
- 右键解压速度和字节进度；解压中的失败、可疑膨胀和不安全路径处理。
- 写入前磁盘与物理内存余量检查，以及解压中的周期性空间复核。
- 归档列表增加 `Ctrl+C`、`Ctrl+X`、`Ctrl+V` 和 `Delete`，支持在未加密、未分卷的 ZIP、7z、TAR 内复制、移动和删除成员；右键菜单提供同样操作。
- 复制和剪切的成员可粘贴到资源管理器；资源管理器确认移动完成后才从原包删除，并留下备份。
- 首次启动提示设置临时目录，路径存入程序同目录的无后缀 `TEMP_D`；“设置 → 更多”可以修改并查看剩余空间，启动时会复核可达性与空间。

## 修复与安全调整

- `TEMP_D` 所选目录下建立专用临时工作目录；确认没有其他实例后，启动时清空旧暂存。剪贴板内容替换、完成剪切和窗口退出后清理成员暂存，7-Zip 内嵌工具使用完立即删除。
- 临时目录的链接和目录联接被拒绝；启动清理、工具清理与剪贴板清理的异常统一附带 StageCode 显示，并补全阶段码登记与英文注释。

- 路径检查现在识别绝对路径、盘符和 `..`；用户另选目录后仅使用安全文件名，并再次校验结果仍在所选目录内。
- 单成员失败或跳过时清理临时输出；重试不会重复累计字节进度。
- 恢复前备份原包；恢复 ZIP 使用唯一名称，不覆盖以前的结果。
- 对读取到的成员内容显式计算 CRC32，与归档提供的 CRC 值比较；无 CRC 元数据的格式仍按可读性判断。
- 文件搜索使用取消令牌防止过时结果覆盖新的查询。
- 新窗口和提示的文字与背景，以及下拉框、复选框、列表、表头、菜单弹层、右键菜单、滚动条和输入框内层均改为设置驱动的动态主题画刷。
- 归档内编辑使用同目录临时文件和原子替换，并保存 `.bak` 原包；失败时原包保持不变，外部修改过的归档需重新打开。无法安全保留空目录或加密属性时拒绝修改。

## 影响范围

核心改动位于 `MainWindow`、`ContextOperationWindow`、`ArchiveService`、`ArchiveWorker`、`SevenZipToolService`、`ContextMenuCommandHandler`、`SettingsWindow` 和新增工具/配置窗口与服务；新增 UI 字符串覆盖 `en-US`、`zh-CN`、`zh-TW`、`zh-HK`、`zh-MO` 资源。
