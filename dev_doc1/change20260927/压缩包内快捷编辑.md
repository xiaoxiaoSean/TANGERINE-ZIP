# 压缩包内快捷编辑

在主窗口的归档文件列表中选中一个或多个文件、目录后，可以使用以下按键。右键菜单提供相同操作，所有文字和背景继续使用动态主题画刷。

| 按键 | 操作 |
|---|---|
| `Ctrl+C` | 将选中成员暂存到配置的临时目录，供压缩包内或资源管理器粘贴 |
| `Ctrl+X` | 暂存成员；归档内粘贴成功后移动成员，或在资源管理器确认移动成功后删除原成员 |
| `Ctrl+V` | 将记录的成员复制或移动到当前浏览的归档目录 |
| `Delete` | 确认后删除选中成员 |

复制或剪切后可双击目录进入目标位置，再按 `Ctrl+V`。复制到已有同名位置时自动使用 ` (2)`、` (3)` 等后缀，避免覆盖原成员。剪切到原目录或自身子目录会被拒绝。目录选择包括其全部后代；重复或重叠的选择只处理一次。快捷键只在归档列表获得焦点时生效，搜索框继续使用标准文字编辑快捷键。

编辑通过独立归档工作进程执行。程序检查磁盘和可用内存，再将归档流式重写为同目录临时文件；成功后使用 `File.Replace` 原子替换，生成带时间戳和随机标识的 `.bak` 原包备份。TAR 写入器需要可定位的成员流，因此逐个暂存成员，并在每次暂存前后复查剩余空间。取消、校验失败、写入失败时清理临时文件，原包保持不变。界面改写后重新读取压缩包，并显示备份位置。如果文件在打开或复制后被外部程序修改，需重新打开并选择成员。

资源管理器粘贴使用 Windows 文件列表剪贴板格式；选中成员先解压到 `TEMP_D` 指定目录下的专属暂存文件夹，再提供给资源管理器。复制可用于可解压的格式；剪切及归档内粘贴只支持未加密、未分卷的 ZIP、7z 和 TAR。资源管理器报告移动完成后，程序还会检查所有暂存入口均已移走，才从原包删除选中成员并保存 `.bak`。复制、跳过或失败时保留原成员。暂存文件在剪贴板仍可能被使用期间保留，因此连续复制大文件会占用临时目录空间；每次暂存前先检查可用空间。剪贴板由当前程序实例提供，关闭程序后不保证继续可粘贴。

RAR、镜像和单文件压缩流拒绝归档内修改。7z/TAR 中如果存在无法由当前写入器保留的空目录，也会拒绝修改。重写会重新压缩成员并将文件名写为 UTF-8；不保证保留原压缩算法、归档注释或特殊扩展元数据。

验证：对临时 ZIP、7z 和 TAR 执行同目录复制、跨目录剪切粘贴、删除、备份存在性与成员内容校验；不存在的 ZIP 成员触发错误后原包哈希不变。独立工作进程完成 ZIP 粘贴并返回备份路径。Windows 剪贴板冒烟测试确认文件列表可读及“移动成功”信号可触发回调；未进行资源管理器窗口人工粘贴回归。项目构建通过，0 警告、0 错误。
