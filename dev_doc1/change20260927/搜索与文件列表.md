# 异步搜索与文件列表

打开压缩包后，列表上方提供搜索框。输入会触发后台并行名称搜索；新输入取消旧搜索，只有最新结果能更新界面。搜索显示压缩包中的完整成员路径，清空搜索框恢复当前目录浏览。

列表三列依次为名称、原始大小和压缩后大小。显示大小自动换算 B/KiB/MiB/GiB/TiB。格式不提供可靠成员压缩大小时显示未知标记，不将 0 误认为真实大小。

选中一行的右键菜单包含“解压此文件到文件夹”和“文件详细信息”。解压沿用目标选择、覆盖冲突及工作进程；详细信息显示完整路径、成员类型、归档格式、原始与压缩后大小、压缩方式、压缩率、节省空间、修改时间、加密状态和 CRC32。压缩率按成员原始大小与压缩后大小计算，压缩后体积更大时可以为负值；缺失或不可靠的元数据明确显示“未知”，目录不计算压缩率。详情弹窗使用当前主题颜色，并可滚动查看。目录仍可双击进入；搜索结果中的目录同样可进入。
