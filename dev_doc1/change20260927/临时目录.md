# 临时目录设置

更新：所有可清理的暂存内容集中在所选目录下的 `TangerineZipWorkspace`。唯一实例启动时清空该专用目录；其他实例存在时保留。新剪贴板替换旧内容、资源管理器剪切完成和窗口退出时清理成员暂存，嵌入 7-Zip 工具在压缩完成后清理。详细生命周期和阶段码见 [临时空间与阶段代码.md](临时空间与阶段代码.md)。

程序同目录下的无后缀文件 `TEMP_D` 以 UTF-8 保存临时目录的绝对路径。首次启动找不到此文件，或路径不可达、不可写、空间不足时，启动界面会提示用户重新选择目录；取消选择则退出。启动检查包括目录存在性、写入探针、至少 64 MiB 的磁盘余量和 16 MiB 的可用物理内存。归档工作进程读取同一配置文件。

“设置 → 更多”显示当前目录及所在卷的可用空间，可再次选择并保存。新路径在写入 `TEMP_D` 前接受相同检查；配置文件在程序目录内通过同目录临时文件替换，并回读确认。设置页继承 `Theme.xaml` 的动态文字、背景和按钮颜色；提示使用主题窗口，文字覆盖英文、简体和繁体资源。

内层 TAR 暂存、WIM 暂存、恢复中间文件、资源管理器剪贴板成员及工具/右键菜单安装包等使用专用子目录。剪贴板成员在供资源管理器粘贴期间保留；复制大文件前按成员原始大小检查目标卷剩余空间。归档重写及最终输出仍在目标文件同目录创建临时文件，以便使用原子替换及保留原包备份；这些输出分别检查所在卷余量。

阶段码 `TMPDR0001` 表示未配置，`TMPDR0002` 表示目录不可达，`RSRCE0001`/`RSRCE0002` 表示磁盘/内存不足，`TMPDR0004` 表示配置保存失败，`TMPDR0005` 表示专用子目录不可用，`TMPDR0006` 表示启动清理失败。系统文件夹选择器由 Windows 显示，应用内文字和背景按外观设置变化。
