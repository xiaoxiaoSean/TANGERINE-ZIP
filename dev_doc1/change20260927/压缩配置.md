# 压缩配置

主窗口和资源管理器右键压缩统一使用以下流程：选择源文件 → 选择输出格式及位置 → 配置压缩 → 执行。普通视图仅显示密码选项及“高级选项”勾选框；本次任务展开后勾选框被锁定，重新开始任务才会复位。程序同目录放置空的无后缀 `ADVANCED_MENU_ON` 文件时，高级配置自动展开，勾选框隐藏。

高级配置用于 ZIP、7z 和 RAR。每个控件旁都标明默认值和风险：算法、等级、字典大小、线程数、内存上限及分卷大小。ZIP 的字典参数不生效；ZIP 可选 Deflate、7z 可选 LZMA2，RAR 使用其原生算法且等级范围为 0–5。互不兼容的算法组合会被拒绝。其他格式采用其原有默认写入器；仅支持密码的格式显示密码选项。

配置随任务传给独立工作进程。ZIP/7z 高级写入由内置 7-Zip 执行，分卷输出以 `.001` 等编号结尾。RAR 高级写入需要程序目录中的官方 `rar.exe`，分卷输出为 `.part1.rar` 等。解压必须保留全部分卷。内存上限通过 Windows Job Object 对外部压缩进程执行强制约束，设置过低会导致压缩失败。执行前检查源文件、目标磁盘和可用物理内存。

密码与其他进程参数一样由 `ArgumentList` 传入外部工具；本机同一用户仍可能在进程运行期间查看其命令行。请在受信任设备上使用。已加密归档无法在忘记密码后恢复。
