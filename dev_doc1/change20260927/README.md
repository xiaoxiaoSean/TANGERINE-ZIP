## 已知边界

完整性检测和可读文件恢复使用 SharpCompress。无法被其打开的镜像或严重破损的目录结构会报告错误；恢复不能重建缺失的数据。逐文件重试/跳过/终止覆盖 SharpCompress、ISO 与单文件压缩流；WIM 由整镜像解码器处理，失败时任务终止。高级压缩参数对 ZIP、7z 和 RAR 开放，其他格式继续使用各自安全的默认写入器。以上限制在各功能文档中详述。
