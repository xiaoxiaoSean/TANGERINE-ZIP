## 页面与文件

设置窗口使用左侧 `TabControl`、右侧内容区域。“基本”保留鼠标光效开关、光晕半径和描边粗细；新“外观”页提供四个颜色按钮，均调用系统颜色选择器。四个按钮依次对应程序 EXE 所在目录中的无后缀名文件：

每一项设置旁都有“恢复默认值”按钮，共七项：鼠标效果开关、光晕半径、描边粗细及下表四种颜色。开关默认**开启**（即删除 `NO_MOUSE_EFFECT` 标记文件），半径默认 `140`，描边粗细默认 `0.95`。恢复通过各设置原有的异步持久化服务执行，文件保存成功后即时应用到所有相关窗口；失败则保留已提交的旧值并显示阶段码。恢复半径或粗细时会等待当前滑块拖动保存任务结束，避免旧保存覆盖默认值。

| 文件 | 用途 | 首次运行默认值 |
| --- | --- | --- |
| `COLOR1` | 文字强调色（普通文字及列表文字） | `#FFFFFF`，纯白 |
| `COLOR2` | 所有 WPF 窗口背景色 | `#000000`，纯黑 |
| `COLOR3` | 所有进度条的已完成部分 | `#FFA500`，橙色 |
| `COLOR4` | 所有进度条的背景部分 | `#FFFFFF`，纯白 |

每个文件只存储一个 `#RRGGBB` 值，使用 UTF-8、无 BOM、不附加空格或换行；不支持透明度。若缺失，启动时以 `CreateNew` 建立默认值，避免覆盖其他进程刚创建的文件。外观页显示当前十六进制值和默认色说明。保存时先写入同目录临时文件，再原子替换目标文件并回读校验；文件写入失败时不会把新颜色广播到界面，临时文件清理失败也会向用户显示阶段码。

## 对比检查

`COLOR1` 与 `COLOR2` 成一组；`COLOR3` 与 `COLOR4` 成另一组。两组均检查 sRGB 相对亮度的对比度，以及 RGB 三通道欧氏距离。最低对比度为 `1.8:1`，最低颜色距离为 `100`；任一不达标即视为过于相近，**先弹窗且不写入任何颜色文件，也不改变当前界面**。采用 `1.8:1` 是为了让指定的默认橙色 `#FFA500` 与白色进度背景保持合法。该阈值只用于阻止几乎相同的颜色，不能保证任意用户配色满足更高等级的无障碍文字对比标准。

如果只恢复一项颜色会使这一组颜色冲突，例如当前文字纯黑、背景纯白，而用户点击“恢复文字默认纯白”，会先说明单项恢复不可行，询问是否把这一组**两项**一起恢复默认。选择“否”不修改文件。选择“是”后按顺序写入两个默认值，并在任一步失败时尝试将两个原值都写回；只有两项都成功才更新应用资源。若回滚也失败，会显示 `COLRS0016` 并告知用户重启时检查颜色配置。由于两个独立文件无法以一次文件系统操作同时替换，进程或系统在两次写入之间突然终止时，下一次启动的对比校验仍会拦截不一致状态并要求修复。

## 启动、恢复与即时生效

`Program.Main` 在创建第一个 WPF 窗口前读取四个文件并验证两组颜色。文件内容不是严格的 `#RRGGBB`、UTF-8 无法解码、空内容或超长内容，均视为数据异常：逐个提示具体文件名、删除不可恢复的后果，并询问是否删除。用户同意后仅删除该文件，再循环读取并按默认值重建；拒绝则程序退出。权限、路径或磁盘故障不是“坏数据”，不会擅自删除，显示异常后退出。

若启动读取到的两个有效颜色仍过于相近，会显示对应颜色名称及阶段码，要求用户通过颜色选择器重新选择这一组的强调色。选择器取消或拒绝修正时退出，不更改文件；仍不符合对比规则时再次要求重选。另一组颜色如果也冲突，会在下一轮单独处理。程序不在冲突状态下打开主窗口。

运行中更改颜色采用异步文件写入；只有通过对比检查且成功持久化后，才替换应用资源字典里的 WPF `SolidColorBrush`。WPF 可能把样式中使用的画刷冻结为只读对象，不能直接改它的 `Color`；替换资源值会让 `DynamicResource` 重新解析，因此已经打开的窗口与之后创建的窗口同步更新。表面色、按钮色和边框色从当前背景/文字色按固定比例混合，以保持层次。目录列表用字体粗细而非固定黄色与普通文件区分，防止亮色背景下看不清。系统原生消息框及系统颜色选择器使用 Windows 自身主题，不属于 WPF 窗口配色范围。

曾出现 `SETWN0005`、`Cannot set a property ... because it is in a read-only state`：配置文件已写入，但画刷被冻结，导致当前窗口未更新，重启后才显示。现改为创建并替换新的画刷资源，不再修改冻结对象；颜色选择后即应更新当前窗口及其他已打开窗口。

## 代码与阶段码

- `Services/AppearanceSettings.cs`：文件校验、颜色对比、异步原子写入和应用资源更新；阶段头 `COLRS`。`0001`–`0004` 为四个无效文件；`0005` 创建失败；`0006` 删除失败；`0007` 选择无效；`0008` 设置时对比不足；`0009`/`0010` 为启动时两组对比不足；`0011` 读取失败；`0012` 临时文件清理失败；`0013` 保存失败；`0014` 启动修复仍不满足对比；`0015` 成对恢复失败；`0016` 回滚失败；`0017` 恢复索引无效。
- `SettingsWindow.xaml(.cs)`：外观侧边页、颜色选择器及七个恢复按钮；`SETWN0004` 选择索引异常，`SETWN0005` 其他选择/保存异常，`SETWN0006` 颜色恢复异常，`SETWN0007` 鼠标开关恢复异常，`SETWN0008` 半径恢复异常，`SETWN0009` 粗细恢复异常。
- `Program.cs`：启动恢复流程；`PROGM0004` 删除失败，`PROGM0005` 选择器/修复失败，`PROGM0006` 其他启动读取失败。
- `Theme.xaml` 和各窗口 XAML：共享动态资源；资源名为 `BackgroundBrush`、`ForegroundBrush`、`SurfaceBrush`、`ButtonBrush`、`BorderBrush`、`ProgressAccentBrush`、`ProgressBackgroundBrush`。
- 所有新增用户文字均有中性英文、`en-US`、`zh-CN`、`zh-TW`、`zh-HK`、`zh-MO` 资源。源代码变量名及注释均为英文。
