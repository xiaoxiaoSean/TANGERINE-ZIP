StageCode format: five uppercase ASCII letters (component head) + four decimal digits (failure branch).
The code is stable across languages. MessageTipGenerator displays it using localized StageCodeTip1/StageCodeTip2 labels.
Callers preserve an existing StageException.StageCode; only unexpected exceptions receive the boundary's fallback code.
