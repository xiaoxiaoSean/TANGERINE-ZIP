# TANGERINE-ZIP-V2.1.1

Changes since v2.1.0.

## English

### Fixes

- Localized the **About TZIP** main menu item for English, Simplified Chinese, and Traditional Chinese (Taiwan, Hong Kong, and Macao). It now follows the selected UI language instead of always appearing in Simplified Chinese.

`fd` is framework-dependent and requires the .NET 10 Desktop Runtime; `sc` is self-contained. Both downloads target Windows x64.

## 中文

相对 v2.1.0 的更新。

### 修复

- 补齐主菜单“关于 TZIP”的英文、简体中文和繁体中文（台湾、香港、澳门）本地化。菜单文字现在随界面语言切换，不再始终显示简体中文。

`fd` 为依赖框架版，需要安装 .NET 10 Desktop Runtime；`sc` 为自包含版。两个附件均适用于 Windows x64。
